# Arcane Bossbound Minecraft Mod

Arcane Bossbound is a Minecraft mod companion for a fantasy boss fight and spell casting modpack, adding a quest driven campaign, first login guidance, starter supplies, expedition food, and a boss trophy item for Minecraft 1.21.1 on NeoForge.

## Install

1. Install Java 21.
2. Install Minecraft Java Edition 1.21.1.
3. Install NeoForge 21.1.172.
4. Build the project with:

   ```bash
   ./gradlew build
   ```

   On Windows, run:

   ```bat
   gradlew.bat build
   ```

5. Copy the generated JAR from `build/libs` into the instance's `mods` folder.
6. Add compatible Minecraft 1.21.1 NeoForge versions of any external content mods used by your modpack, such as Twilight Forest, The Aether, Terramity, Tetra, Iron's Spells 'n Spellbooks, and Farmer's Delight.
7. Launch the game with the NeoForge profile.

## Use

1. Enter a world with the mod installed.
2. On first login, receive a Quest Compass and a two line campaign introduction.
3. Run `/ff quests` to display the six campaign chapters.
4. Follow the campaign prompts through spell mastery, dimension exploration, Tetra weapon forging, cooking, and boss progression.
5. Use the Arcane Ration as an always edible food item that restores 8 nutrition with 0.8 saturation.
6. Keep the Boss Trophy item as a simple victory keepsake.
7. Open the Fantasy Frontiers creative tab to access the three added items in creative mode.

The campaign text references external mods, but those mods are not bundled with this project and are not declared as required dependencies by the companion mod.
